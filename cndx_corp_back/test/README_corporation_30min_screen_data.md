# 企業マスタ画面からの30分値登録用データ

`prepare_corporation_30min_screen_data.py` は、お客さま企業マスタ照会・編集画面で供給地点特定番号を登録し、LMMBCS-API-04の30分値同期を確認するためのデータを検証DBに作成します。企業基本・企業詳細、同意書取得組織、拠点、EPの30分値1日分、ARVE情報を用意します。`TEP`組織と指定した金融機関の組織が既にある場合は、その行を再利用します。30分値の登録先テーブルには直接投入しません。

## 実行方法

`TEST_DATABASE_URL` に検証DBのSQLAlchemy接続URLを設定します。法人番号と供給地点特定番号には、検証DBで使われていない値を指定してください。取得日は既定で実行日の日本時間の日付になります。

```powershell
$env:TEST_DATABASE_URL = 'postgresql+psycopg2://USER:PASSWORD@HOST:5432/DBNAME'
$args30 = @(
  '--corp-number', '9999999999001',
  '--supply-point', '9999999999999999999001',
  '--consent-org-id', 'UT30-BANK01'
)
python cndx_corp_back/test/prepare_corporation_30min_screen_data.py @args30
python cndx_corp_back/test/prepare_corporation_30min_screen_data.py @args30 --apply
```

最初のコマンドはDBを変更せず、投入前の重複とマスタの存在を確認します。`--apply` は1回だけ実行してください。同じ法人番号や供給地点特定番号が登録済みなら、既存データを守るため処理を中止します。都道府県コード`13`は共通マスタに登録されている必要があります。別のコードを使う場合は`--prefecture-code`で指定します。

## 画面での確認

1. `/master/mscs01` で法人番号`9999999999001`を検索し、「30分値同期試験企業」を開きます。
2. 編集画面の既存拠点「30分値試験拠点」で、供給地点特定番号に`9999999999999999999001`を入力して保存します。事業所コード`123`、お客さま番号`0000000000123`、同意書取得経路`01`、同意書取得組織「30分値試験用金融機関」は準備済みです。
3. `db_corp.t_electricity_data_30min`で、法人番号・拠点ID・供給地点特定番号が一致する1行を確認します。取得日は実行日、欠測件数は2、不正値件数は3、電力量1～48はそれぞれ`1.125`～`48.125`です。ARVE事業所コードは`123`、ARVEお客さま番号は`0000000000123`になります。

新規拠点の登録分岐を確認するときは、投入時に`--new-office`を付けます。この場合、拠点マスタは作成されません。画面で拠点を追加し、同意書取得経路`01`、同意書取得組織「30分値試験用金融機関」、拠点名・所在地、事業所コード`123`、お客さま番号`0000000000123`、上記の供給地点特定番号を入力して保存します。取得日は直近5年以内の日付にしてください。

## 削除

検証後、次のコマンドで、このPGが作成した企業と関連データ、および画面操作で登録した1拠点・30分値を削除できます。削除対象の企業は`created_by=UT_API04_30MIN`で確認し、想定外の拠点や30分値があれば中止します。既存の同意書取得組織と`TEP`組織は削除しません。

```powershell
python cndx_corp_back/test/prepare_corporation_30min_screen_data.py @args30 --cleanup
```

このPGは試験用データだけを準備します。画面へのログインに使う利用者と権限は、検証環境に登録済みのものを使用してください。

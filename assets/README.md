# 青い助言枠の電球アイコン
見本の`report2.pdf`から取り出した青い電球を`ICON.png`として同梱しています。運用で別の画像を使う場合は、このファイルを差し替えてください。
- 元画像のサイズ：幅90×高さ89ピクセル
- ファイル名：`ICON.png`（大文字・小文字も一致させる）
- 透過PNGに対応。

`rendering/icons.py`が読み込み、No.4〜No.7の青い助言枠の左上へ幅7.5mm・元の縦横比で配置します。アイコンがない場合やサイズが違う場合はエラーになります。各ワーカーで一度だけ読み込み、メモリ上で再利用するため、画像差し替え後はワーカープロセスを起動し直してください。

# 青い助言枠の電球アイコン
指定された青い電球の画像を、このフォルダーへ`ICON.png`として配置してください。
- 元画像のサイズ：幅90×高さ89ピクセル
- ファイル名：`ICON.png`（大文字・小文字も一致させる）
- 透過PNGに対応。画像本体はこの配布ソースには同梱していません。

`rendering/icons.py`が読み込み、No.4〜No.7の青い助言枠の左上へ幅3.3mm・元の縦横比で配置します。アイコンがない場合やサイズが違う場合はエラーになります。各ワーカーで一度だけ読み込み、メモリ上で再利用するため、画像差し替え後はワーカープロセスを起動し直してください。
